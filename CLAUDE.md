# Claude agent instructions

## PR review requests

Before creating, updating, or merging a pull request, read and follow [the agent-requested Codex review policy](AGENTS.md#agent-requested-codex-review). Classify the complete final diff; skip ordinary changes by default and prioritize concrete high risks within the shared owner-wide limit of one review request per four eligible PRs. Uncertainty alone does not trigger review. Do not automate PR review through Actions; preserve the documented existing release-tag exception in AGENTS.md.
